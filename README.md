# AetherSync downloads

AetherSync is a Windows companion for AION 2 with event alerts, a live DPS meter, and a crafting planner.

Visit [Releases](https://github.com/Kahfi123/AetherSync-Releases/releases) for the Windows 11 x64 portable ZIP and its SHA-256 checksum. Extract the ZIP, keep the supplied `aethersync.auth.json` beside `AetherSync.exe`, and sign in with Discord. Install [Npcap](https://npcap.com/#download) separately for live capture.
