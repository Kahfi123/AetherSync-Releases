# AetherSync downloads

AetherSync is a Windows companion for AION 2 with event alerts, a live DPS meter, and a crafting planner.

Download `AetherSync-<version>-win-x64.exe` from the latest release, run it on Windows 11 x64, and sign in with Discord. The executable includes the .NET Desktop Runtime. Install Npcap separately for live capture. [GitHub Releases](https://github.com/Kahfi123/AetherSync-Releases/releases) · [Npcap downloads](https://npcap.com/#download)

Use the SHA-256 in the release notes to verify your download. [Third-party notices](notices/)
